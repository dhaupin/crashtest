# About

Crashtest is one arm of the struct family: a set of small tools that keep a
suite of repos honest about itself. It is authored and maintained in public.

## Who builds it

Crashtest is built by [Rook @ Creadev.org](https://creadev.org) and by AI
agents working in the open. Every change lands through a pull request with its
gates run, and the repo history keeps the receipts.

The target we trust least is our own code. The repo dogfoods itself in CI: the
committed ledger holds 49 `REFUSED` findings on our own hardened demo app, and
that run has already paid for real bugs.

## The struct family

Crashtest does not stand alone. The spec is
[packstruct](https://github.com/dhaupin/packstruct); the artifact audit is
[poststruct](https://github.com/dhaupin/poststruct); the visual memory is
[eyestruct](https://github.com/dhaupin/eyestruct); the governance layer is
[govstruct](https://github.com/dhaupin/govstruct); the factory is
[monoforge](https://github.com/dhaupin/monoforge). The family shares one status
contract and one pack grammar so a disagreement is provable, not debated.

## License and provenance

Crashtest is MIT-licensed. The tool and the site are both open source, so the
honest summary is: read the code. The
[site terms](https://crashtest.creadev.org/terms) and
[site privacy](https://crashtest.creadev.org/privacy) pages carry the surface
facts in plain language.
