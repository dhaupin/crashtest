# refusal-battery/packstruct@fdf1be5 - the transcribed battery corpus

Byte-exact transcriptions (verified with `cmp` at ingest time, 2026-10-24)
of the **packstruct** side of the shared refusal battery:
`labs/refusal-battery/*.json` (17 shapes + `missing-public-dir`) and
`labs/refusal-matrix.packstruct.json` (packstruct's committed golden
column, renamed here as `packstruct-column.json`), all taken from
**dhaupin/packstruct @ fdf1be5** ("lint --deep + packstruct refusal-matrix
column").

The crashtest half of the matrix (our loader's observed column over these
same bytes) is GENERATED by `scripts/gen-refusal-battery.cjs` and lives at
`labs/refusal-matrix-crashtest.json`. The first observed run of that column
was posted as the crashtest column on [dhaupin/crashtest#25](https://github.com/dhaupin/crashtest/issues/25) -
everything here transcribes; nothing invents (the same law the
`packstruct-backfill` corpus runs under).

## Rules

1. **Re-ingest, don't hand-edit.** Refreshing these bytes = re-copy from a
   pinned packstruct checkout + re-run the generator + re-derive any moved
   agreement pin in the test, all in the SAME commit.
2. **The documented host differences are pinned, not fears.** Six rows
   legitimately disagree (packstruct refuses / crashtest accepts, or
   vice-versa semantics): `version-major-only`, `description-empty`,
   `armedByKey-empty`, `name-dir-mismatch`, `manifest-missing`,
   `missing-public-dir`. The generator README (see scripts/) carries the
   engine cite for each; the pin test fails loudly if any of them silently
   drifts to agreement or new disagreement (that is a finding, not noise).
3. **A known upstream anomaly is on record:** packstruct's committed column
   claims `refused [schemaVersion]` on `schemaVersion-missing` while their
   own battery bytes still CARRY `"schemaVersion": 1` (their generator
   never dropped the key - re-observed on #25: their own linter accepts the
   bytes). Our ingest transcribes their column faithfully and the test pins
   OUR column only; their generator fix is theirs to land.
