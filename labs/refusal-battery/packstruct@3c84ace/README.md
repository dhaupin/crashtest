# refusal-battery/packstruct@3c84ace - the transcribed battery corpus

Byte-exact transcriptions (verified with `cmp` at re-ingest time,
2026-10-24) of the **packstruct** side of the shared refusal battery at
**dhaupin/packstruct @ 3c84ace**:

- `*.json` - the battery shapes (18 after the corpus grew: packstruct added
  `armedByKey-non-string` with the 5a56281 fold). Each file instructs the
  materialization (`dirName`, manifest bytes or placeholders, whether to
  write the entry file) and carries packstruct's own expectation.
- `packstruct-column.json` - their per-shape observed tool column
  (their `labs/refusal-matrix.packstruct.json`).
- `packstruct-golden.json` - their joined golden set
  (their `labs/refusal-matrix.golden.json`): packstruct column + crashtest
  column + per-row status/tally, with honest annotations.

The crashtest half of the matrix (our loader's observed column over these
same bytes) is GENERATED by `scripts/gen-refusal-battery.cjs` and lives at
`labs/refusal-matrix-crashtest.json`. First observed on
[dhaupin/crashtest#25](https://github.com/dhaupin/crashtest/issues/25);
re-observed after their generator fix on [crashtest#27 item 1](https://github.com/dhaupin/crashtest/issues/27).
Everything here transcribes; nothing invents.

## The fix this re-ingest carries (crashtest#27 item 1)

packstruct 5a56281 fixed the emitter bug we flagged on #25: the battery
bytes for `schemaVersion-missing` now truly OMIT the key, and our loader's
REQUIRED_KEYS refuses them `[schemaVersion]` - the cell flips to REFUSED,
matching the golden row's post-fix prediction
(`status: "re-verified-after-fix"`). The old upstream-anomaly is over; its
pin in test/refusal-battery.test.js now asserts the LANDED state.

## Rules

1. **Re-ingest, don't hand-edit.** Refreshing these bytes = re-copy from a
   pinned packstruct checkout + re-run the generator + re-derive any moved
   pin in the test, all in the SAME commit.
2. **The documented host differences are pinned, not fears.** Seven rows
   legitimately disagree (packstruct refuses / crashtest accepts, or
   vice-versa semantics): `version-major-only`, `description-empty`,
   `armedByKey-empty`, `armedByKey-non-string` (joined at this re-ingest),
   `name-dir-mismatch`, `manifest-missing`, `missing-public-dir`. Each
   carries its engine cite in scripts/gen-refusal-battery.cjs; the pin test
   fails loudly if any drifts silently (a new disagreement is a FINDING).
3. **Their engine-side columns are theirs.** We transcribe their verdicts
   faithfully and pin OUR column only; parity assertions read the golden's
   packstruct rows. When their side moves, re-ingest + re-derive here in
   the same reviewed commit.
